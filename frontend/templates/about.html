About WaterGuard

WaterGuard is a Machine Learning based water quality analysis system designed to predict whether water is safe or unsafe for human consumption. The system analyzes different chemical parameters present in water and provides instant prediction results through an interactive web application.

Project Objective

The main objective of this project is to create an easy-to-use platform that helps users quickly analyze water quality using Artificial Intelligence. Clean and safe drinking water is essential for health, and this system aims to simplify the process of water safety prediction.

How It Works

Users enter different water quality parameters such as Aluminium, Arsenic, Barium, Chloramine, Nitrates, Radium and others. The input data is processed using a trained Random Forest Machine Learning model, which predicts whether the water is safe or unsafe.
